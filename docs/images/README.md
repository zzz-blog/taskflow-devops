# 截图目录

把你跑起来后的真实截图放到这里，并在 README 中引用，例如：

- `grafana-dashboard.png` —— Grafana「TaskFlow 应用监控」看板
- `github-actions.png` —— CI 流水线全绿运行记录
- `gitops-commit.png` —— CD 自动 bump 镜像版本的提交记录
- `kubectl-pods.png` —— `kubectl get pods -n taskflow` 输出
- `load-test.png` —— 压测结果（RPS / P95）
- `architecture.svg/.png` —— 端到端架构图（README 已引用）
- `app-running.png` —— 本地运行中的应用看板（API 状态灯 + 任务 CRUD）

> 简历或 README 里有真实运行截图，说服力会大幅提升（见 docs/resume.md 第一节）。
